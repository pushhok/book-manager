# Менеджер книг на Vue 3

Приложение для управления списком книг с возможностью:
- Добавления новых книг (название, автор, жанр)
- Отметки книг как прочитанных
- Оценки прочитанных книг (от 1 до 5 звезд)
- Удаления книг
- Фильтрации (все/непрочитанные/прочитанные)
- Поиска по названию или автору
- Статистики
- Сохранения в localStorage

## Установка и запуск

```bash
npm install
npm run dev
